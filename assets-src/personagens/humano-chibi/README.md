# Humano chibi

Personagem humano chibi modular (corpo, cabelo, roupas em camadas). Regras: [`../CONTRATO.md`](../CONTRATO.md).

| Pasta | Conteúdo | Git |
|---|---|---|
| `entrega/v02/` | PNGs no contrato + `contrato.json` | sim |
| `previas/v02/` | comparações e animações escolhidas (≤ 1 MB cada) | sim |

- **v01** (arquivado, só local, ~577 MB): base frontal, 12 expressões e 12 cabelos frontais, testes de encaixe,
