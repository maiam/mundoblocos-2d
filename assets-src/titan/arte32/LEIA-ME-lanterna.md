# Lanterna da Margem · 32 px

Ícone redesenhado a partir do modelo high-poly. O sprite mede 32 × 32 px, com alfa binário, em PNG RGBA e WebP sem perdas. Use escala inteira para a UI, como 32 → 64 px, com `image-rendering: pixelated`.

O item mantém ID 8. Os arquivos são sprites individuais de uma célula. A integração deve mapear o novo recorte na hotbar, na bolsa e no livro de receitas antes de trocar a arte. O modelo 3D high-poly permanece como referência visual.

A prancha usa os dois ícones de 16 px como comparação e simula o novo sprite sobre basalto e âmbar. O teste dentro do jogo ainda está pendente.
